

This is a frontend solution based on React 18, Next.js 14, Ant Design, and TypeScript, designed to provide a ready-to-use solution for developing medium to large-scale projects.

## Project

### Installation

```bash
pnpm install
```

### Run

```bash
npm run dev
# or
yarn dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser to view the result.

## Environment Requirements

```bash
"node": ">=18.17.0"
```

## Base Components

- [NextJS](https://nextjs.org/docs) is a React framework for building full-stack web applications
- [Ant Design](https://ant-design.antgroup.com/components/overview-cn?from=msidevs.net) UI component library
- [Tailwindcss](https://www.tailwindcss.cn/docs/installation) Atomic CSS framework (optional to use, but highly recommended)
- [ZUSTAND](https://awesomedevin.github.io/zustand-vue/docs/introduce/start/zustand) State management
- [ahooks](https://ahooks.js.org/zh-CN) A library of high-quality and reliable React Hooks
